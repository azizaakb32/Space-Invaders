# 🚀 Space Invaders

A 3D Space Invaders-style game developed with **Unity and C#**.

## 🎮 About the Project

This project is a Unity-based 3D game inspired by the classic **Space Invaders** arcade game.

The project was created to practice Unity game development, C# scripting, gameplay programming, and working with game objects and mechanics.

## 🛠️ Technologies

* 🎮 Unity
* 💻 C#
* 🧩 Object-Oriented Programming
* 🔧 Git & GitHub

## 🎯 Project Focus

* Player gameplay
* Enemy gameplay
* Shooting mechanics
* Game object interactions
* Collision handling
* Game logic
* Unity UI
